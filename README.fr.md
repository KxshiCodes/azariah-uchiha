# Page web d'un personnage fictif - Azariah Uchiha

Une petite page web inspirée de l'univers de Naruto, mettant en scène mon personnage original : Azariah Uchiha.

Ce projet a été créé à l'origine pour me remettre dans le bain avec HTML et CSS, avant de me lancer dans un projet Java full-stack.

J'y reviendrai de temps en temps pour tester de nouvelles fonctionnalités, améliorer le design et faire évoluer le site au gré de mes idées et de mon inspiration.

## Technologies utilisées

- HTML
- CSS
- JavaScript (à venir)

## Statut

Petit projet personnel toujours en cours. J'y ajouterai de nouvelles fonctionnalités et des améliorations quand j'aurai envie d'expérimenter de nouvelles choses.
